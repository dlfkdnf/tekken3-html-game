# 철권3 - 3D 격투 게임

HTML5와 Three.js를 사용한 철권3 스타일의 3D 격투 게임입니다.

## 📋 기능

### 현재 구현된 기능
- ✅ 2명의 플레이어 캐릭터 (카주야, 진)
- ✅ 3D 리얼타임 격투 시스템
- ✅ 약 공격 / 강 공격 시스템
- ✅ 콤보 시스템 (연속 공격 시 피해 증가)
- ✅ 체력 시스템
- ✅ 스태미나 시스템
- ✅ 중력 및 점프 물리
- ✅ 캐릭터 애니메이션
- ✅ 실시간 HUD (체력바, 스태미나)
- ✅ 승리 시스템

## 🎮 게임 컨트롤

### 플레이어 1 (파란색)
| 키 | 동작 |
|---|---|
| ↑ | 앞으로 이동 |
| ↓ | 뒤로 이동 |
| ← | 왼쪽 이동 |
| → | 오른쪽 이동 |
| Space | 점프 |
| Z | 약 공격 |
| X | 강 공격 |

### 플레이어 2 (빨간색)
| 키 | 동작 |
|---|---|
| W | 앞으로 이동 |
| A | 왼쪽 이동 |
| S | 뒤로 이동 |
| D | 오른쪽 이동 |
| Space | 점프 |
| O | 약 공격 |
| P | 강 공격 |

## 🚀 시작하기

### 요구사항
- 모던 웹 브라우저 (Chrome, Firefox, Safari, Edge)
- 인터넷 연결 (Three.js CDN 사용)

### 실행 방법
1. 저장소를 클론합니다:
```bash
git clone https://github.com/dlfkdnf/tekken3-html-game.git
```

2. `index.html` 파일을 웹 브라우저에서 엽니다
   - 또는 로컬 서버에서 실행:
```bash
python -m http.server 8000
# 또는
npx http-server
```

3. "게임 시작" 버튼을 클릭하여 게임을 시작합니다

## 🎯 게임 시스템

### 체력 시스템
- 초기 체력: 100
- 약 공격: 5 피해
- 강 공격: 15 피해
- 체력이 0이 되면 게임 종료

### 콤보 시스템
- 0.2초 이내에 연속 공격 시 콤보 카운트 증가
- 각 콤보 단계당 +2 추가 피해
- 콤보는 2초 이상 공격하지 않으면 리셋

### 스태미나 시스템
- 초기 스태미나: 100
- 약 공격 소비: 5
- 강 공격 소비: 15
- 시간에 따라 천천히 회복
- 스태미나가 부족하면 공격 불가능

### 물리 시스템
- 중력 시뮬레이션
- 점프 메커닉
- 경기장 경계 충돌
- 캐릭터 간 충돌
